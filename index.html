Features

Everything in v0.0.7, nothing you didn't ask for.

Time ships with a focused set of browsing fundamentals, done well, rather than a long list of half-built apps.

Liquid Glass interface

A translucent, blurred glass UI with adjustable accent color, blur density, and specular highlights — plus Dark Focus, Light Minimalist, OLED Deep Black, and System Sync theme presets.

Keyboard-first tabs

Open, close, and cycle tabs entirely from the keyboard. Closing the active tab hands focus to the next one over, and every core action has a shortcut.

One-click bookmarks

Toggle a bookmark straight from the omnibox star. Organize into a bookmarks bar, custom folders, and pinned quick-access slots.

Built-in downloads manager

Pause, resume, cancel, or reveal a file in Finder. Executable file types get a plain-language warning before they land on disk.

Local-first history

History and bookmarks live in an on-device database, not a cloud account. There's nothing to sign into and nothing syncing behind your back.

Omnibox & command routing

One bar for URLs and search. Type a web address and Time routes you there; type anything else and it dispatches a search — instantly, with ⌘L to jump straight in.

Installation

Installing on macOS

Five steps, no account required.

Download the DMG

Grab TimeBrowser-0.0.7.dmg from the download section above.

Open the disk image

Double-click the downloaded file to mount it. A window will appear with the Time Browser app icon.

Drag Time Browser to Applications

Drag the app icon onto the Applications shortcut in the same window, then eject the disk image.

Launch it

Open Time Browser from your Applications folder or Launchpad.

First launch on an early-access build: if macOS flags the app as being from an unidentified developer, right-click (or Control-click) the app and choose Open, or approve it under System Settings → Privacy & Security. This is standard for early builds that aren't notarized yet — you only need to do it once.

You're in

Time Browser opens to time://newtab. Press ⌘T for a new tab or ⌘L to jump into the omnibox.

Documentation

Quick start

Navigate from anywhere

Press ⌘L to select the omnibox, type a URL or a search, and hit Enter. Time works out which one it is.

Manage tabs by keyboard

New tab with ⌘T, close with ⌘W, and jump to any of the first nine with ⌘1–9.

Make it yours

Open Quick Settings with ⌘, to switch themes, adjust the accent color, and tune the glass blur density.

FAQ

Good to know

What is Time Browser?
A lightweight, keyboard-first desktop browser with a liquid glass interface. It's built on standard web technology (HTML/CSS/JS) and packaged as a native desktop app with Electron.
What platforms are supported?
The 0.0.7 macOS build is packaged and tested today. A Windows build is planned; check back on this page or the GitHub repo for availability.
Is an account required?
No. There's no sign-in and no cloud account. History and bookmarks are stored locally on your device.
Does it collect telemetry?
No. Omnibox searches, history logging, and navigation events produce zero outbound requests to analytics servers — this is a defined acceptance criterion for the release.
How do I install it?
Download the .dmg, open it, and drag Time Browser into your Applications folder. Full steps are in the installation section above.
Where is the documentation?
The full specification and keyboard shortcut matrix live on the documentation page, linked from the navigation bar above.
